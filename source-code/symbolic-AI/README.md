# Symbolic AI – Source Code

This directory contains example code for the **Symbolic AI** chapter.

## Installation

The examples use **SWI-Prolog**. Install it on macOS with:

```bash
brew install swi-prolog
```

For other platforms, see the [SWI‑Prolog download page](https://www.swi-prolog.org/download/stable).

## Running the examples

The Prolog snippet from the manuscript can be saved as `example.pl` and run with:

```bash
swipl -s example.pl
```

Feel free to experiment with the `semweb` library as shown in the chapter.

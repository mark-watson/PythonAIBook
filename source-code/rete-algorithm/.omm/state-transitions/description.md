The engine's recognize-act lifecycle as implemented by `ReteEngine.run` / `step` / `_step_internal` (`rete/engine.py`). Matching happens continuously as working memory changes; `run()` repeatedly selects and fires one instantiation. It stops when nothing is eligible (quiescence), when an RHS calls `ctx.halt()`, or when `max_cycles` firings have happened. Halt is not sticky: the flag lives on the per-firing `RuleContext`, so calling `run()` again resumes.

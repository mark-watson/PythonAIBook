The path a fact takes from assertion to rule firing and back. A user (or an RHS through deferred `RuleContext` mutations) asserts a `Fact`; `WorkingMemory` wraps it in a timestamped `WME`; the alpha network filters it by exact type and constant tests into alpha memories; join and negative nodes combine it with existing tokens; completed tokens become `Instantiation`s on the agenda; the engine picks one, fires its RHS, and the RHS's queued mutations re-enter at the top. Retraction runs the same path in reverse, removing dependent tokens and instantiations.

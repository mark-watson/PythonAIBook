`WorkingMemory` class: `dict[int, WME]` store. `assert_fact` increments a per-engine timestamp, builds `WME(fact, wme_id=ts, timestamp=ts)`, and calls `network.add_wme`. `retract` removes and calls `network.remove_wme`. `modify` = `dataclasses.replace` + retract + assert (new id, so refraction allows re-firing). `facts()` / `wmes()` iterate with optional type filter; `clear()` retracts everything.

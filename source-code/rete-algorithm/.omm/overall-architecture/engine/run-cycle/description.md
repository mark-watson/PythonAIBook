`ReteEngine.run` / `step` / `_step_internal`: one recognize-act cycle filters the conflict set by refraction, calls the strategy to choose one `Instantiation`, records it in `_fired`, builds a `RuleContext`, maps binding names to the action's parameters via `inspect.signature` (skipping the first `ctx` param), executes the RHS, flushes `ctx.print` messages, then applies deferred mutations. `run` loops until no eligible instantiation, `ctx.halt()`, or `max_cycles`.

`rete/engine.py` — `ReteEngine` and `WorkingMemory`. `ReteEngine` owns the conflict set, refraction set (`_fired`, keyed by `(rule_name, frozenset(wme_ids))`), strategy, `ReteNetwork`, and tracing. It exposes the `rule` decorator / `add_rule`, `assert_fact` / `retract` / `modify`, `run(max_cycles)` / `step`, and introspection (`facts`, `wmes`, `conflict_set`, `trace`, `get_trace`). `WorkingMemory` assigns monotonic timestamps (also used as WME ids), stores WMEs by id, and pushes adds/removes into the network; `modify` = retract + assert of a `dataclasses.replace` copy.

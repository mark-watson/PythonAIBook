A lightweight, pure-Python Rete forward-chaining rule engine packaged as `rete/`. Users define facts as frozen dataclasses inheriting from `Fact`, write rules with the `@engine.rule(Pat(...), ~Pat(...), salience=N)` decorator, assert facts, and call `engine.run()`. Internally, rules compile into an alpha network (type dispatch + per-field constant tests + alpha memories) and a beta network (join / negative / production nodes). Complete matches become `Instantiation`s in a shared conflict set; a pluggable strategy (LEX, MEA, priority-only) picks one to fire per recognize-act cycle. Six domain example scripts and a pytest suite sit on top of the package.

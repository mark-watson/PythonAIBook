`rete/context.py` — `RuleContext`, the first argument to every RHS. Queues `assert_fact`, `retract`, and `modify` (retract + `dataclasses.replace` assert) into pending lists; `halt()` sets a stop flag; `print()` appends to a trace log; `wmes()` lets an action look up WMEs outside its LHS; `token_wmes` exposes the matched WMEs. `_apply(engine)` replays retracts first, then asserts, after the action returns.

`rete/patterns.py` — LHS building blocks. `PatternOp` subclasses each implement `test(value)`: `Var` (binds, always passes), `Eq`, `Gt`, `Lt`, `Ge`, `Le`, `In`, `Contains`, `Match` (regex search), `Test` (arbitrary predicate). `Cond` holds `fact_type`, `field_constraints: dict[str, PatternOp]`, `negated`; `~cond` flips negation; `var_bindings()` maps variable→field. Factories `Pat(Type, **kw)` / `cond(...)` auto-wrap plain values in `Eq`.

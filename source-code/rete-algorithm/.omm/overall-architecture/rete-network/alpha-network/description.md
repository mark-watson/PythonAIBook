`rete/alpha.py`. `AlphaNetwork.type_dispatch` maps `type(fact)` → entry nodes; `add_wme` pushes the WME through each `AlphaTestNode` chain (one field test per node, `getattr(fact, field)`), landing in `AlphaMemory`s that store the WME and right-activate their successor beta nodes. After each add it walks the entry nodes to build a `wme_to_memories` reverse index so `remove_wme` can call `AlphaMemory.remove` (→ `right_remove` on successors) without a full scan. Dispatch is by exact type, so subclasses of a fact type do not match a pattern on the base class.

`NegativeNode`: implements `~Pat(...)`. Keeps `_blocked: id(token) → (token, set of blocking WMEs)` and `_passed: id(token) → token`. A new token passes downstream only if no WME in the alpha memory `_matches` it. A new right WME moves matching passed tokens to blocked (and retracts them downstream via `left_remove_token`); retracting a blocker unblocks tokens whose blocker set becomes empty and re-propagates them.

`rete/beta.py`. Performs inter-element joins over `Token`s. `JoinNode` joins left tokens (from a parent `BetaMemory`, or `EMPTY_TOKEN` at the head) with right WMEs from its `AlphaMemory`, checking `JoinTest`s, re-checking the cond's non-Var ops, and extracting new `Var` bindings. `NegativeNode` passes a token only while no matching WME exists, tracking blockers per token. `BetaMemory` stores intermediate tokens. `ProductionNode` turns complete tokens into `Instantiation`s (rule name, token, salience, action, conds, max WME timestamp) in the shared conflict set.

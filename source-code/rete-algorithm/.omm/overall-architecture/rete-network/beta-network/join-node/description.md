`JoinNode`: `left_activate(token)` tries every WME in its alpha memory; `right_activate(wme)` tries every token in its parent `BetaMemory` (or `EMPTY_TOKEN` if it is the first condition). `_try_join` checks `JoinTest`s (shared-variable equality), the cond's non-Var ops, and Var consistency, returning new bindings or `None`. Successful joins produce `token.extend(wme, bindings)` sent to children. `right_remove` / `_propagate_remove` push WME removal downstream.

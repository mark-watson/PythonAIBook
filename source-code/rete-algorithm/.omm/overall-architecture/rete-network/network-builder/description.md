`ReteNetwork` in `rete/network.py`. `add_rule(name, conds, action, salience, conflict_set)`: for each `Cond`, `_get_or_build_alpha` returns a cached `AlphaMemory` keyed by `(fact_type, frozenset((field, repr(op))) of non-Var constraints)` or builds a fresh linear `AlphaTestNode` chain ending in a new memory. Then it walks conds in order, computing `JoinTest`s for variables already bound by earlier conds (`_compute_join_tests`), creating a `JoinNode` or `NegativeNode`, inserting a `BetaMemory` between conditions, and attaching a `ProductionNode` after the last one. `add_wme` / `remove_wme` forward to the alpha network.

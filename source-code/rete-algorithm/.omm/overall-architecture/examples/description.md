Six runnable domain demos at repo root: `example_medical.py` (diagnosis → treatment chaining, NCEs), `example_hospital_triage.py` (multi-resource Patient+Bed+Staff matching, salience scheduling), `example_ecom_pricing.py` (discount rules, NCE completion barrier), `example_portfolio_rebalance.py` (aggregation + drift-based buy/sell), `example_network_security.py` (event consumption, counters, threshold alerts), `example_smart_home.py` (sensor fusion, occupancy inference). Each defines its own frozen `Fact` dataclasses, a module-level `ReteEngine`, decorated rules, then asserts facts and runs. Type-checked by pyrefly, but not run by pytest.

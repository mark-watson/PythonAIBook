`rete/conflict.py` — conflict-resolution strategies, each `list[Instantiation] -> Instantiation` via `max(...)`: `resolve_lex` (salience → max WME timestamp → number of conds), `resolve_mea` (salience → first-condition WME timestamp → number of conds), `resolve_priority_only` (salience; ties go to earliest in list). `STRATEGIES` registry plus `resolve_strategy(name_or_callable)` which raises `ValueError` for unknown names.
